Stone Game
Difficulty: MEDIUM | Max Score: 50
Alice and Bob play a game with piles of stones. There are an even number of piles arranged in a row, and each pile has a positive integer number of stones piles[i].

The total number of stones across all piles is odd, so there are no ties.

Alice and Bob take turns, with Alice starting first. On each turn, a player can take the entire pile of stones from either the beginning or the end of the row.

The game continues until all piles are taken. The player with the most total stones wins.

Assuming both players play optimally, return true if Alice wins, or false if Bob wins.



Input Format

First line contains an integer n (number of piles, guaranteed to be even).

Second line contains n space-separated integers representing piles.



Output Format

Return a boolean (true or false).

For STDOUT: Print true or false.



Constraints

2 ≤ n ≤ 500
n is even.
1 ≤ piles[i] ≤ 500
The sum of all elements in piles is odd.




Example 1

Input:
4
5 3 4 5

Output:
true
Explanation: Alice can choose either the first 5 or the last 5. If Alice chooses the first 5, the remaining row is [3, 4, 5]. Bob can take 3 or 5. Regardless of Bob's move, Alice can secure a higher total score and win.





﻿Example 2

Input:
4
3 7 2 3

Output:
true
Explanation: Alice can always win by choosing all even-indexed piles or all odd-indexed piles.
